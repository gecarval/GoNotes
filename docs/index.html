A quick reference for building terminal apps in Go with Bubble Tea, Bubbles and Lip Gloss (v2).

Bubble Tea

The framework. Your program is a Model with three methods: Init, Update and View. Everything that happens is a Msg; anything slow is a Cmd.

charm.land/bubbletea/v2

Bubbles

Ready-made components (text inputs, lists, tables, viewports, spinners…). Each one is a tiny Bubble Tea model you embed in yours.

Lip Gloss

Styling and layout. CSS-like styles (colors, padding, borders) that render to strings, plus Join/Place helpers to compose them.

the loop

Bubble Tea follows the Elm architecture. The runtime owns the loop: it sends every event to Update as a Msg, redraws with View, and runs any Cmd you return in the background. You never block and never draw by hand.

func (m model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    switch msg := msg.(type) {
    case tea.KeyPressMsg:
        if msg.String() == "q" {
            return m, tea.Quit           // a Cmd: "please quit"
        }
    case tea.WindowSizeMsg:
        m.width = msg.Width              // remember the size for View
    }
    var cmd tea.Cmd
    m.input, cmd = m.input.Update(msg)   // forward to a Bubbles component
    return m, cmd
}

how this site is organized

  • cheatsheet: every exported function of the three libraries, grouped by topic, one line each with a short description (extracted with go doc from the exact versions in this repo's go.mod).
  • examples: small, complete programs for the functions that only make sense together (Focus + Blink, Tick loops, Batch vs Sequence, list + WindowSizeMsg + SetSize, FrameMsg for progress…), colored by module and rated by difficulty. Thumbnails are the real View() output.
  • Names in the cheatsheet that appear in an example link to the examples that use them, and each example links back to the cheatsheet entries it uses.
